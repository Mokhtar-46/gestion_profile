# gestion_profile

**Gestion Profile** est une application web permettant aux institutions, comme les universités par exemple, de **gérer les profils de leurs utilisateurs**.

Chaque type d'utilisateur dispose de **rôles spécifiques** et de **droits d'accès adaptés** à ses fonctions.
